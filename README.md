## 先搞清楚它賣的是什麼：住宅 IP、雙 ISP、機房 IP 的差別

一般 VPS 給你的 IP 註冊在資料中心 ASN 下，TikTok、亞馬遜、PayPal 這類平台一查 ASN 類型是 hosting，就會提高驗證頻率、限流，嚴重時直接封。麗薩主機主推的雙 ISP 家寬住宅 IP，ASN 類型與組織登記都指向當地寬頻運營商，風控看到的是一個普通的美國、香港或日本家庭在寬頻上網。這類 IP 資源本身稀缺，價格自然壓不下來，這也是它比同配置機房 VPS 貴的原因。

「雙 ISP」比「原生 IP」更進一步。原生 IP 只代表 IP 註冊在本地，歸屬仍可能是機房；雙 ISP 要求 ASN 類型與組織兩項都是運營商屬性。第三方測評普遍提到美國住宅 IP 段在 Scamalytics 的欺詐值為 0，這類結果可以作為參考，但別當成你自己的實測。

要注意的是，麗薩主機並非所有套餐都是住宅 IP。¥199／年那款預設給的是非美國原生 IP，要原生得選 ¥299／年，或加 ¥20／月更換（年付可免費換一次）。買之前先確認這條，比研究 CPU 型號重要得多。
